# سعید آنالیز — نسخه‌ی PWA (نصب روی صفحه‌ی اصلی آیفون)

این نسخه همون فایل HTML اصلی شما رو (بدون هیچ تغییری در منطق، فرمول‌ها، رنگ‌بندی و
ظاهر) به یک **PWA** تبدیل کرده — یعنی با چند تا فایل اضافه (manifest، آیکون‌ها،
service worker) که فقط باعث می‌شن Safari اجازه بده اپ رو به صفحه‌ی اصلی آیفون اضافه
کنید و با آیکون اختصاصی، بدون نوار آدرس مرورگر، مثل یه اپ واقعی باز بشه.

**بر خلاف نسخه‌ی قبلی (IPA)، این روش نه حساب Apple Developer می‌خواد، نه گواهی،
نه GitHub Actions — فقط باید فایل‌ها یه‌جا با HTTPS میزبانی بشن.**

## فایل‌ها

```
saeed-analiz-pwa/
├── index.html          # همون فایل اصلی شما + تگ‌های PWA/آیکون iOS
├── manifest.json        # اسم، رنگ، آیکون‌های اپ
├── sw.js                 # service worker ساده (فقط پوسته رو کش می‌کنه، نه داده‌های زنده)
└── icons/                # آیکون با تم تحلیل کریپتو در همه‌ی سایزهای لازم iOS
```

## مرحله ۱ — میزبانی روی GitHub Pages (رایگان، بدون بیلد)

1. یک ریپازیتوری جدید در GitHub بسازید (خصوصی یا عمومی، فرقی نداره).
2. کل محتوای همین زیپ رو push کنید:
   ```bash
   git init
   git add .
   git commit -m "Saeed Analiz PWA"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```
3. توی خود ریپو: **Settings → Pages → Build and deployment → Source: Deploy from a branch**
   → برنچ `main` و پوشه‌ی `/ (root)` رو انتخاب کنید و Save بزنید.
4. بعد از حدود ۱ دقیقه، آدرس اپتون این می‌شه:
   ```
   https://<username>.github.io/<repo>/
   ```

## مرحله ۲ — نصب روی آیفون

1. همون لینک بالا رو با **Safari** (نه کروم یا هیچ مرورگر دیگه، نه از داخل تلگرام/اینستاگرام) روی آیفون باز کنید.
2. دکمه‌ی Share (مربع با فلش رو به بالا) رو بزنید.
3. **Add to Home Screen** رو انتخاب کنید → Add.
4. آیکون جدید (با طرح کندل‌استیک/خط روند) روی صفحه‌ی اصلی گوشی میاد؛ با زدنش، اپ
   بدون نوار آدرس مرورگر و با آیکون اختصاصی باز می‌شه.

همین. هیچ حساب اپل، هیچ گواهی، هیچ بیلدی لازم نیست.

## محدودیت‌های PWA روی iOS (صادقانه بگم)

- این یک اپ واقعی داخل App Store نیست؛ فقط یک میان‌بر Safari با ظاهر تمام‌صفحه‌ست —
  برای استفاده‌ی شخصی خودتون دقیقاً همون حسی که خواستید رو می‌ده.
- اگه محتوای `index.html` یا آیکون رو بعداً عوض کنید، ممکنه آیفون تا چند روز نسخه‌ی
  قبلی رو کش کرده باشه؛ برای آپدیت فوری، اپ نصب‌شده رو حذف و دوباره Add to Home
  Screen کنید.
- اگه گوشیتون در حالت Low Power Mode یا اپ چند روزیه باز نشده، iOS ممکنه حافظه‌ی
  اپ رو آزاد کنه و با باز کردن دوباره، صفحه از اول لود می‌شه (دیتای زنده که مشکلی
  نداره، چون اصلاً همیشه لحظه‌ای از Binance گرفته می‌شه).
- پوش نوتیفیکیشن یا اجرای بک‌گراند مثل اپ‌های واقعی اپ‌استور نداره — چیزی هم که
  در فایل اصلی شما نبود، پس تفاوتی در عملکرد فعلی ایجاد نمی‌کنه.

## نکته‌ی امنیتی

اگه ریپو رو Public بذارید، هرکسی می‌تونه لینک GitHub Pages رو ببینه و اپ رو باز کنه
(چون هیچ لاگین/پسوردی نداره). اگه می‌خواید فقط خودتون دسترسی داشته باشید، ریپو رو
**Private** کنید — GitHub Pages برای ریپوهای private هم با پلن‌های GitHub Pro/Team/
Enterprise یا حساب سازمانی در دسترسه؛ اگه حساب رایگان دارید و ریپو باید private
بمونه، به‌جای GitHub Pages می‌تونید از سرویس‌های رایگان دیگه مثل Netlify یا
Vercel (که هاستینگ استاتیک private/محدود هم دارن) استفاده کنید — ساختار فایل‌ها
دقیقاً همینه و بدون تغییر روی اون‌ها هم کار می‌کنه.
