# سعید آنالیز — نسخه‌ی اپ آیفون

این پروژه همون فایل HTML تحلیل بازار کریپتوی شما رو (بدون هیچ تغییری در منطق، محتوا یا ظاهر —
همون رنگ‌بندی، همون کارت‌ها، همون فرمول‌ها و تایم‌فریم‌ها) داخل یک پروژه‌ی
[Capacitor](https://capacitorjs.com) بسته‌بندی کرده که در GitHub Actions به‌صورت خودکار
تبدیل به یک اپ نصب‌شدنی روی آیفون (فایل `.ipa`) می‌شه، با یک آیکون و اسپلش‌اسکرین
جدید و شیک با تم تحلیل بازار (کندل‌استیک سبز/قرمز + خط روند صعودی آبی‌فیروزه‌ای،
هم‌رنگ با تم خود اپ).

فایل اصلی شما بدون تغییر داخل `www/index.html` قرار گرفته.

## ⚠️ نکته‌ی مهم و صادقانه قبل از شروع

اپل اجازه نمی‌ده هیچ اپی—even فقط برای گوشی خودتون—بدون **امضای دیجیتال (code signing)**
روی آیفون نصب بشه. این یعنی برای این‌که GitHub بتونه در انتها یک اپ نصب‌شدنی بهتون بده،
به یکی از دو مسیر زیر نیاز دارید:

### مسیر پیشنهادی (پایدار، لینک مستقیم نصب روی گوشی)
یک حساب **Apple Developer Program** (سالانه ۹۹ دلار) از
https://developer.apple.com/programs
با این حساب: یک گواهی توزیع (Distribution Certificate) و یک پروفایل Ad-Hoc می‌سازید
که UDID گوشی خودتون توش ثبت شده. بعدش هر بار که این ورک‌فلو در GitHub اجرا بشه،
یک لینک نصب مستقیم (`itms-services://…`) تولید می‌کنه که کافیه توی Safari گوشی باز کنید
و بزنید Install — دقیقاً همون چیزی که خواستید: «فقط یک عدد آپ برای نصب».

### مسیر جایگزین رایگان (پیچیده‌تر، هفته‌ای نیاز به تمدید)
اگه نمی‌خواید هزینه‌ی سالانه بدید، می‌تونید فایل `.ipa` تولیدشده رو با ابزارهایی مثل
**AltStore** یا **Sideloadly** با اپل آیدی رایگان خودتون روی گوشی نصب کنید، ولی این
امضا هر ۷ روز منقضی میشه و باید با وصل‌کردن گوشی به کامپیوتر دوباره نصبش کنید.
این مستندات پایین برای مسیر پیشنهادی (Ad-Hoc) نوشته شده؛ اگه مسیر رایگان رو خواستید
فقط تا مرحله‌ی دانلود artifact (بخش ۵) پیش برید و فایل `.ipa` رو با AltStore/Sideloadly نصب کنید.

من (Claude) نمی‌تونم گواهی اپل یا حساب دولوپر براتون بسازم — این تنها بخشی از کاره که
اپل نگهش می‌داره و باید خودتون یک‌بار انجامش بدید؛ بقیه (بیلد، بسته‌بندی، آیکون، ورک‌فلو)
همه آماده و خودکاره.

## ۱) ساخت گواهی و پروفایل در سایت اپل (یک‌بار، حدود ۱۵ دقیقه)

1. وارد https://developer.apple.com/account شوید (بعد از عضویت در Developer Program).
2. **Certificates → +** یک **Apple Distribution** certificate بسازید و دانلودش کنید
   (باید از قبل یک CSR با Keychain Access مک بسازید؛ اگه مک ندارید، از یک سرویس
   آنلاین ساخت CSR/p12 یا از یک دوست با مک کمک بگیرید — این تنها قدمیه که واقعاً
   به یک مک (ولو موقت) نیاز داره).
3. فایل certificate رو با کلید خصوصی‌اش در Keychain Access به فرمت **.p12** اکسپورت
   کنید و یک رمز عبور روش بذارید.
4. **Devices → +** و UDID گوشی خودتون رو ثبت کنید (از تنظیمات گوشی یا Finder/iTunes
   یا سایت‌هایی مثل `get.udid.io` پیدا می‌شه).
5. **Identifiers → +** یک App ID با Bundle ID دقیقاً برابر `com.saeed.analiz` بسازید
   (همون چیزی که در `capacitor.config.json` نوشته شده).
6. **Profiles → +» نوع **Ad Hoc** بسازید، همون App ID و certificate بالا و گوشی ثبت‌شده
   رو انتخاب کنید، بسازید و دانلودش کنید (فایل `.mobileprovision`).

## ۲) آماده‌سازی مخزن GitHub

1. یک ریپازیتوری جدید (خصوصی بهتره) در GitHub بسازید.
2. محتوای همین فایل زیپ رو داخلش push کنید:
   ```bash
   git init
   git add .
   git commit -m "Saeed Analiz iOS app"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo>.git
   git push -u origin main
   ```
3. در **Settings → Pages** همون ریپو، منبع رو روی برنچ `gh-pages` بذارید (این برنچ
   خودش با اولین اجرای ورک‌فلو ساخته می‌شه، پس اگه اول بار دیده نشد نگران نباشید).

## ۳) اضافه‌کردن Secrets

در **Settings → Secrets and variables → Actions → New repository secret** این‌ها رو اضافه کنید:

| نام Secret | مقدار |
|---|---|
| `IOS_DIST_CERT_P12_BASE64` | خروجی `base64 -i Certificate.p12 \| pbcopy` |
| `IOS_DIST_CERT_PASSWORD` | همون رمزی که موقع اکسپورت p12 گذاشتید |
| `IOS_PROVISION_PROFILE_BASE64` | خروجی `base64 -i Profile.mobileprovision \| pbcopy` |
| `KEYCHAIN_PASSWORD` | یک رمز دلخواه و تصادفی (فقط برای keychain موقت روی سرور GitHub) |

(Team ID، Bundle ID و اسم پروفایل نیازی به وارد کردن دستی ندارن — ورک‌فلو خودش از
داخل همون فایل `.mobileprovision` استخراجشون می‌کنه.)

## ۴) اجرای ورک‌فلو

به تب **Actions** ریپو برید، ورک‌فلوی **Build iOS App (سعید آنالیز)** رو باز کنید و
**Run workflow** رو بزنید (یا هر پوشی روی برنچ `main` خودش اجراش می‌کنه). حدود
۵ تا ۱۰ دقیقه طول می‌کشه.

## ۵) نصب روی گوشی

بعد از اتمام موفق ورک‌فلو:

- **راه مستقیم:** به آدرس زیر برید (توی خود Safari آیفون، نه از طریق تلگرام/اینستاگرام
  چون اون اپ‌ها اجازه‌ی نصب itms-services نمی‌دن):
  ```
  https://<your-username>.github.io/<repo>/
  ```
  و دکمه‌ی «نصب روی آیفون» رو بزنید.
- **راه پشتیبان:** از تب همون اجرای Actions، artifact با اسم `saeed-analiz-ipa` رو
  دانلود کنید (یک `.ipa`) و با AltStore / Sideloadly / Apple Configurator روی گوشی نصبش کنید.

## نکات

- پروفایل Ad-Hoc و گواهی توزیع هرکدوم ۱ سال اعتبار دارن؛ بعد از یک سال باید یک بار
  دیگه از سایت اپل تمدیدشون کنید و secrets رو آپدیت کنید.
- اگه گوشی عوض کردید یا UDID جدید اضافه کردید، باید پروفایل Ad-Hoc رو دوباره بسازید
  (چون فقط گوشی‌های ثبت‌شده توش اجازه‌ی نصب دارن) و secret مربوطه رو آپدیت کنید.
- منطق اپ (اتصال به API بایننس، محاسبه‌ی اندیکاتورها، پلن معامله، ردیابی پوزیشن) دقیقاً
  همونیه که خودتون نوشتید؛ فقط داخل یک پوسته‌ی بومی iOS اجرا می‌شه، بدون نوار آدرس
  مرورگر، با آیکون و اسپلش‌اسکرین اختصاصی.
- اگه صفحه‌ی خالی یا خطای شبکه دیدید، مطمئن شید IP/کشوری که آیفون توشه به
  `api.binance.com` دسترسی داره (بایننس بعضی مناطق رو مسدود می‌کنه؛ این محدودیت
  خود بایننسه و ربطی به این اپ نداره).
